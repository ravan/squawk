Interfaces should explain themselves.

A deterministic long-form page for checking document-anchored feedback against dark surfaces, long scroll distances, and changing viewports.

Start with the reading path

A good review begins with hierarchy. Readers should know where to look before decoration asks for attention, and every annotation should remain tied to the thing it describes.

This section creates distance from the page header without relying on animation, remote fonts, or network content.

Leave enough room for evidence

Long pages expose coordinate mistakes quickly. The viewport moves, but feedback belongs to document space and must return to the same content after every scroll.

The warning belongs with the paragraph beside it, not with the current viewport position.

This paragraph is the stable review target. Its measured border box remains deterministic so an arrow can point into the copy and a pen stroke can underline the final line without drifting when the page scrolls away and back.

Return to the same place

Scroll restoration is useful evidence only when the content and its annotation coordinates are unchanged. This final section supplies enough distance to move both targets fully out of view.
